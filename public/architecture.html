Before the first message

Install the dependencies, set the key in the launching shell, and choose the working directory. The SDK starts a local runtime; Claude inference happens through the configured provider. No Managed Agents agent or environment IDs are required.

Download the UML SVG
01

1. Ask: What files are here?

Student → Browser + host. The browser submits the exact question. The terminal sample supplies the same constant without needing a web server.

02

2. Check inherited key and input

Browser + host → Browser + host. The launching process must inherit a key. The browser host also validates the prompt before starting the runtime.

03

3. query(prompt, options); cwd set

Browser + host → Agent SDK. The host creates one query object. Its options select sample-workspace as cwd and make only Glob available.

04

4. Send prompt and Glob tool definition

Agent SDK → Claude API. The runtime sends the task and the Glob tool definition to the model. It does not supply the browser reference list as an answer.

05

5. Request Glob file discovery

Claude API → Agent SDK. The model chooses Glob. An assistant tool_use block exposes the requested tool and pattern as observable progress.

06

6. Run Glob in sample-workspace

Agent SDK → Demo folder. The SDK executes the built-in listing tool locally. This does not require a Bash command or a Read tool.

07

7. Return matching file paths

Demo folder → Agent SDK. The local tool returns the file paths it actually found, including the nested src/hello.ts file.

08

8. Send the tool result to Claude

Agent SDK → Claude API. The SDK handles the next model interaction with the tool result. The host does not implement a manual Messages API loop.

09

9. Produce the final answer

Claude API → Agent SDK. Claude produces a human-readable answer informed by the returned paths. The wording may vary across runs.

10

10. Yield tool, text and result messages

Agent SDK → Browser + host. The same async iterator yields progress and a final SDK result. One query call can include multiple model turns.

11

11. Print results or render safe text

Browser + host → Browser + host. The terminal prints selected output with console.log; the browser renders projected events using textContent.

12

12. Compare files; check final status

Browser + host → Student. Compare the named files with the demo folder and inspect the final result status. Text or a tool call alone does not establish completion.

One query call can contain a model → tool → model round trip. The browser does not provide a prewritten answer. Its host reference list is separate from the agent’s discovery. Only Glob is available, and cwd is a working-directory choice rather than an operating-system sandbox.
