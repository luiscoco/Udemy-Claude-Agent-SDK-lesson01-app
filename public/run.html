01

Install the SDK and choose TypeScript

For this app use Node.js 24 or newer, npm, and a model-accessible Anthropic API key. On Windows, Git for Windows may be needed for Git Bash. Start a new project using:

mkdir my-agent
cd my-agent
npm init -y
npm pkg set type=module
npm install @anthropic-ai/claude-agent-sdk@0.3.310
npm install --save-dev tsx typescript @types/node
mkdir sample-workspace
"Hello, students!" | Set-Content sample-workspace/notes.txt

This teaches installation from scratch. Save the standalone source shown below as agent.ts in that project. For the completed application, clone it instead:

git clone https://github.com/luiscoco/Udemy-Claude-Agent-SDK-lesson01-app.git
cd .\Udemy-Claude-Agent-SDK-lesson01-app
npm ci

In the original presentations workspace, the local directory is:

cd .\agent-sdk\lesson01-getting-started
npm ci
02

Set your API key in the same shell

In the PowerShell terminal that will run the agent, replace the placeholder with your own key. The presence check prints only true or false.

$env:ANTHROPIC_API_KEY = "your_api_key"
# Check presence without printing the key:
node -e "console.log(Boolean(process.env.ANTHROPIC_API_KEY))"

macOS/Linux Bash alternative:

export ANTHROPIC_API_KEY="your_api_key"
node -e 'console.log(Boolean(process.env.ANTHROPIC_API_KEY))'

This assignment applies to the current shell and its child processes. Repeat it in a new terminal. The SDK does not automatically read .env. Keep the key out of code and Git.

03

Run the sample and print results

From the completed application root, in the same configured shell:

npm run sample

The sample asks exactly What files are here?. Watch for a Glob tool call, the names notes.txt, src/hello.ts and todo.md, and a final success result. Wording, turn count and cost can vary. A tool round trip often needs more than one model turn.

For your from-scratch project, run npx tsx agent.ts instead. Its folder contains the demo file you created in step 1.

04

Optional: use a local .env file explicitly

For repeated classroom runs, copy the safe template without overwriting an existing file:

if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
npm run sample:env
ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3100

The sample:env script explicitly loads this file through Node’s startup option. A key already set in the shell takes precedence. To use only the file in this PowerShell session, first run Remove-Item Env:ANTHROPIC_API_KEY -ErrorAction SilentlyContinue. On Windows, if needed, add CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe.

05

Run the web application

npm start
# Open http://127.0.0.1:3100

The web command loads an optional .env file too. Keep its terminal open. Click Run query once, compare the response with the host reference, then follow the architecture and code pages. Starting the server makes no model request. Each submitted prompt may incur API usage. Stop the server with Ctrl+C when finished.

06

Inspect the standalone sample and check your work

import { query } from "@anthropic-ai/claude-agent-sdk";
import { resolve } from "node:path";

// Run from the project root, after setting the key in this shell.
if (!process.env.ANTHROPIC_API_KEY) throw new Error("Set ANTHROPIC_API_KEY in this shell first.");

for await (const message of query({
  prompt: "What files are here?",
  options: {
    model: process.env.CLAUDE_MODEL || "claude-sonnet-4-6",
    cwd: resolve("sample-workspace"),
    tools: ["Glob"],
    allowedTools: ["Glob"],
    systemPrompt: "Use Glob to list relative file paths in the current directory only. Do not invent names or read contents.",
    settingSources: [], mcpServers: {}, plugins: [], persistSession: false,
    maxTurns: 4, maxBudgetUsd: 0.15,
  },
})) {
  if (message.type === "assistant") {
    for (const block of message.message.content) {
      if (block.type === "text") console.log(block.text);
      if (block.type === "tool_use") console.log(`Tool: ${block.name}`);
    }
  }
  if (message.type === "result") {
    console.log(`Result: ${message.subtype}`);
    if (message.subtype !== "success" || message.is_error) process.exitCode = 1;
  }
}

npm test

Troubleshooting

SymptomWhat to check
Missing keySet ANTHROPIC_API_KEY in this terminal before npm run sample, or explicitly use sample:env.
Authentication/model errorCheck the active shell key, model access and billing. Restart the web server after configuration changes.
Runtime/Git Bash missingRun npm ci with optional dependencies enabled. Check the Git Bash executable path on Windows.
Wrong filesCheck cwd. This app deliberately points to sample-workspace, not the repository root.
Limit resultRead the actual final subtype. Tool activity alone is not success.
Port in useIf this app is already running, open its printed URL. Stop its original terminal with Ctrl+C to restart. For another service, choose a different PORT.
