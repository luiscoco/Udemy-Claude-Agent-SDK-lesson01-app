Your first three steps.

01

Install the SDK

Create a Node project, choose TypeScript, install the Agent SDK and run TypeScript with tsx.

02

Set the key in the same shell

Set ANTHROPIC_API_KEY in PowerShell or Bash before starting the agent. Child processes inherit it; another terminal does not inherit a later assignment.

03

Ask the first question

Submit exactly “What files are here?” and print the assistant text and final outcome.

04

Choose a working directory

cwd points to sample-workspace. The question refers to that directory, not your entire computer or the folder holding .env.

05

Observe a real tool call

Glob lists file paths. tools makes it available; allowedTools pre-approves it. Shell, file-reading and editing tools are not enabled.

06

Check completion

A tool request and assistant text are progress. Check the final result subtype and error flag before reporting success.

Choose your language

This complete application uses TypeScript, following the course preference. Python is also supported by the Agent SDK; its package name is claude-agent-sdk, installed with pip install claude-agent-sdk. The commands, source files and tests in this app use Node, npm and TypeScript.

Use the official quickstart for the Python alternative. Do not mix a Python virtual environment’s commands with the TypeScript run instructions.

Try explaining: What does “here” mean? Why does setting a key in a different terminal not configure this process? Why are tools and allowedTools separate options? Why can one query need more than one model turn?
